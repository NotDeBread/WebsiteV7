Modded Enemies Getting Started First decide whether you want your enemy to be a standard Enemy, Miniboss, or Boss and keep in mind what object you are going to be appending your enemy data to.
  • Standard Enemies can spawn every wave based on thier credits value. Use the enemies object.
  • Minibosses spawn once every 25 waves. Use the minibosses object.
  • Bosses spawn once every 100 waves. Use the bosses object.
Creating an enemy 
enemies.exampleEnemy = {
    name: 'Example Enemy'
}
Enemy Attributes All attributes are optional unless specified.
Attribute Description
name (string) Defines the enemy's name. Used in sandbox tooltips and bossbars.
desc (string) Defines the enemy's description. Used in sandbox tooltips.
color (array) [r,g,b] Defines the enemy's description. Used in sandbox tooltips.
texture (string) Defines the texture of the enemy. Use the file path relative to the graphics/enemies/ folder. For example, for an enemy with the texture exampleEnemy.png, make sure the texture is in the graphics/enemies/ folder and set the enemy's texture value to 'exampleEnemy.png'.
size (number) Defines the enemy's size in pixels.
health (number) Defines the enemy's health. If the health is set to Infinity, the damage delt to the enemy will be shown, like the dummy enemies.
speed (number) Defines the enemy's speed in pixels/tick.
meleeDamage (number) Defines the amount of damage the enemy deals to the player when colliding with them.
credits (number) (required) Defines the amount of credits the enemy is worth in the wave system. If the credits is set to Infinity it will be marked as a "Sandbox Only" enemy.
projectile (object) See Projectiles.
Enemy Events Enemy events are functions that run when specific things related to that enemy occur.
Event Description
tick(enemy) Runs every tick the enemy is alive.
onSpawn(enemy) Runs when the enemy is spawned.
onDamage(enemy) Runs when the enemy is damaged.
onDeath(enemy) Runs when the enemy is killed.
onPlayerCollision(enemy) Runs when the player collides with the enemy.
