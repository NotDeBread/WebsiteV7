DEBREAD.SPACE

debread.space is my current longest standing project, being active for about 4 years now. I'm never happy with the way my website looks so it has changed a lot over the years. Right now, I'm actually pretty content with the way everything is designed right now so don't expect any major changes soon. This version of the website is supposed to resemble an old style site or something you might find on neocities.

When I was first getting into web dev my first site was actually The Eddie Site, made all the way back in the beginning of 2022.

STUFF I LIKE

The game I'm currently hyperfixated on is The Binding of Isaac, which I'm currently trying to achieve dead god on (this will never happen). Some other games I've played extensively are Balatro, Geometery Dash, ULTRAKILL, Celeste, and TUNIC.
